# Welcome to the Wediggit Student Portal — macOS 27 Edition 🎓

This course prepares you as an IT support specialist, Helpdesk engineer, or system administrator in modern Apple enterprise environments. Across 16 hands-on lessons, you will train directly on **macOS 27 (Golden Gate)** for Apple Silicon while mastering hybrid fleet support for organizations also running **macOS 26 (Tahoe)** and legacy Intel Macs.

## What You'll Find Here

* **Learning Guide:** A concise field reference for every lesson featuring learning objectives, key terminology, comparison tables, essential CLI commands, critical paths, visual aids, and dedicated **"In the Field: Supporting macOS 26 & Mixed Fleets"** callouts. *(Note: Embedded audio podcasts and video recaps are delivered in Hebrew).*
* **Hands-On Lab:** Practical, GUI-first step-by-step exercises simulating real-world enterprise support workflows on macOS 27.

## How to Get Started

Use the navigation menu on the **left** to jump between lessons.
*(On smaller screens, open the menu using the three-line menu icon in the upper-left corner).*

!!! tip "Dark Mode"
    Use the sun/moon toggle icon in the top navigation bar to switch between Light Mode and Dark Mode at any time.

!!! tip "Instant Course-Wide Search"
    Click the search bar at the top (or press `S` on your keyboard) to instantly search for any command, concept, DDM policy, or system path across all 16 lessons.

Good luck!
